# YouTube Auto-Skip Ads & Intros

*A Chrome extension designed for educational purposes to demonstrate browser extension development concepts. This project is not intended to bypass YouTube’s ad revenue system or encourage unauthorized modifications of YouTube's services.*

**Users should adhere to YouTube's Terms of Service and consider subscribing to YouTube Premium for an ad-free experience. This extension is not affiliated with, endorsed by, or sponsored by YouTube or Google.**

## Overview
YouTube Auto-Skip Ads & Intros is a Chrome extension that automatically skips ads and video intros on YouTube based on timestamps, providing a smoother viewing experience.

## Features

- Automatically skips YouTube ads when the skip button appears
- Automatically skips intros in videos based on timestamps
- Customizable intro skip times for specific videos
- Simple toggle switches to enable/disable features

## Installation

### From Source Code
1. Clone this repository
2. Open Chrome and navigate to `chrome://extensions/`
3. Enable "Developer mode" (toggle in the top-right)
4. Click "Load unpacked" and select the extension directory

## Usage

1. Navigate to YouTube
2. The extension will automatically skip ads when they appear
3. Click the extension icon to:
   - Toggle ad skipping on/off
   - Toggle intro skipping on/off
   - Add custom intro times for specific videos
